# Cloud Posse Context Provider

Use the Cloud Posse Context provider to create a context that can be shared among the modules in your solution. A
context is a set of named properties and values used to generate consistent resource labels and tags. You must
configure the provider with the properties in the context before you can use it.

This provider is intended to be a replacement for Cloud Posse's
[terraform-null-label](https://github.com/cloudposse/terraform-null-label) module, providing more flexibility through
custom property names, validation, and case transformations.

Use the navigation to the left to read about the available data sources.

## Example Usage

```terraform
terraform {
  required_providers {
    context = {
      source  = "cloudposse/context"
      version = ">= 0.4.0"
    }
  }
}

# Configure the Context Provider
provider "context" {
  delimiter = "-"
  enabled   = true

  properties = {
    namespace   = { required = true }
    tenant      = {}
    stage       = {}
    environment = {}
    name        = { required = true }
  }

  property_order = ["namespace", "tenant", "stage", "environment", "name"]

  tags_key_case   = "title"
  tags_value_case = "none"

  values = {
    namespace   = "acme"
    tenant      = "core"
    stage       = "prod"
    environment = "uw2"
    name        = "example"
  }
}

# Generate a delimited label: "acme-core-prod-uw2-example"
data "context_label" "this" {}

# Generate tags from the context values
data "context_tags" "this" {}

# Read back the provider configuration
data "context_config" "this" {}
```

## Data Sources

- [`context_label`](data-sources/label.md) - Generates labels from context values using either a delimiter or a Go template string.
- [`context_tags`](data-sources/tags.md) - Generates a map of tags from context values with configurable case transformations.
- [`context_config`](data-sources/config.md) - Reads the current provider configuration as a data source.

## Schema

### Optional

- `delimiter` (String) The default delimiter to use for labels created by the provider.
- `enabled` (Boolean) A boolean value to enable or disable the provider.
- `properties` (Attributes Map) A map of properties to use for labels created by the provider. (see [below for nested schema](#nestedatt--properties))
- `property_order` (List of String) The default order of properties to use for labels created by the provider.
- `replace_chars_regex` (String) The regex to use for replacing characters in labels created by the provider. Any characters that match the regex will be removed from the label.
- `tags_key_case` (String) The case to use for the keys of tags created by the provider. Valid values are: none, camel, lower, snake, title, upper.
- `tags_value_case` (String) The case to use for the values of tags created by the provider. Valid values are: none, camel, lower, snake, title, upper.
- `values` (Map of String) A map of values to use for labels created by the provider.
